# ccmon

Claude Code Monitor — monitors Claude Code sessions.

## Build / Run / Test

- `bun install` — install dependencies
- `bun test` — run tests
- `bun run dump` — dump all project states as JSON
- `bun run dump --watch` — watch mode for dump
- `bun run serve` — start HTTP + WebSocket server

TypeScript runs natively via Bun, no compilation step needed.
